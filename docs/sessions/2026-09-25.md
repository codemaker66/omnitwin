The accepted addon set is exact SH position invalidation, parallel prefix plus
batched submission, and lazy CPU scratch. Lazy scratch avoids 23.506 MiB per
full-count native draw during ordinary WebGPU and worker-managed WebGL until
that draw's first synchronous CPU sort, such as a WebGL capture. The draw then
retains that scratch for its lifetime; worker scratch is independent. Parallel
prefix adds 2 KiB of CPU backing and 2 KiB of GPU storage per sort. These are
source-derived allocation differences, not measured heap/VRAM reductions.

Decoder scheduling selects one fetch/decode worker for positive reported memory
≤4 GiB or positive integral processor count ≤4; unknown memory plus ≤6 processors
and explicit coarse-pointer/no-hover also selects one. Other or unknown cases
retain two. This can trade complete-load time for lower overlapping allocations;
it does not change the separate sort worker or rendering quality.
