## T-644 — whole-frame GPU/CPU optimization, a profiler that names the bottleneck, and the report

Blake asked (verbatim, 29 September): "optimize GPU and CPU performance without sacrificing quality visual quality (<1%). Continue until 5 consecutive iterations yield less than 5% improvement in overall time frame, when complete give me a html report of the results. also want a profiler with x12 top stats to track and find out where performance can be improved, track a 20 second average. include a copy to clipboard button along with pause/play/reset. also optimize for our proprietary technology for common gpu and cpu specs and phone specs so we squeeze all the value in the most efficient ways."

The work began on 29 September as "T-640"; while it was paused by a usage limit another task took
T-640 on master (The Amissing Book narration), so this work is T-644 and its commits were relabelled
before pushing. Codex ran the same brief on 25 September (T-634, merged in PR #35: 6.6% on a
render-only metric and the first 20-second profiler). This pass measures whole application frames.
Working files: `D:/claude/perf-20260929/` on the build PC (harness `bench/`, receipts `evidence/`,
report inputs `report/`); measurement branch `claude/perf-20260929`, shipped branch
`claude/t644-frame-time` (master merged).

Result, head to head on the RTX 4090 (Grand Hall, 6.03 M splats, four declared workloads,
A-B-C-C-B-A, all six arms clean, 4 October 05:45-06:47): 4.282 → 2.291 ms per frame (−46.5%).
Turning 4.228 → 2.104 ms, walking 4.845 → 2.179 ms, settled view at pixel ratio 2 5.280 → 2.632 ms,
throttled phone profile 2.776 → 2.248 ms (runs varied up to 2× within an arm). Largest image
difference 0.103% MAE (SSIM ≥ 0.9986) against a before-vs-before floor of 0.061%. Report:
https://claude.ai/artifact/YX861gvCJqo76x3v473yNN (private to Blake until shared).

Iterations (each a control/candidate pair in A-B-B-A order, under the 1% image guard):
- 1, sort-time culling (`f9545509`): +37.9%; the GPU sort fell 4.17 → 0.46 ms because behind-camera
  splats had all landed in one bin and serialised the sort's atomics. Kept.
- 2, algebraic major axis instead of trigonometry: −4.9% (no real change). Rejected.
- 3, footprint cull (`94f2cd4e`): +2.7%. Kept.
- 4, 16 splats per GPU instance (`6cb272ef`): GPU draw 1.82 → 1.35 ms; whole frames −0.2% that night
  because the shared PC paced frames at ~2.7 ms. Kept.
- 5, lighting only the drawn splats (`af244f96`): lighting pass while walking 0.567 → 0.345 ms;
  desktop +1.6%. Kept.
- 6, quads ending at the 1/255 opacity contour (`19778303`): +4.1%; GPU draw −8% at pixel ratio 1 and
  −9% at 2. Kept. Iterations 2-6 each moved frame time by less than 5%, so the loop stopped.

Profiler (`a0d4b7e5`, `b31d3543`): twelve stats over a rolling 20-second window with Pause, Play,
Reset and Copy report (`venviewer.profiler.v2`): FPS, frame mean/p95/p99, bottleneck (busy share of
the median frame interval; "unknown" when a side is unmeasured), CPU submission, GPU draw, GPU sort +
light, splats drawn after culling, draw calls, long tasks (unavailable where the browser does not
report them) and tracked memory. Open with `?profiler=1` or the backquote key in development.
