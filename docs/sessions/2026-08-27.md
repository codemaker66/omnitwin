## Two defects found by adversarial review, both fixed

1. **Transform bound to the room, not the asset.** A registered package would
   have been positioned using the staged XGRIDS walk's origin — wrong place for a
   reviewed asset. `runtimeAssetViewTransformForRoom(room, source)` now requires
   the source, so no call site can omit it. Regression pinned.
2. **Lexical path containment escaped by a Windows directory junction.**
   `mklink /J` needs no administrator rights; a junction inside the staging root
   passed the string check while resolving outside it. Realpath is now resolved
   and re-checked before any bytes are read. Pinned by a filesystem-level test.
