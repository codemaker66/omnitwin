# Session log — 2026-08-04

## T-539 — Trades House leaflet and Craft quiz, made workable by any agent

Blake supplied the leaflet and quiz as a Claude Design project and asked that
the work be set up so other LLMs — including other Claude accounts — can pick
it up and work on it seamlessly.

The Design MCP could not authenticate in this environment (`/design-login`
needs an interactive terminal), and the project had not been seeded into the
workspace. It did not need to be: T-483 already imported the same artwork on
10 July, and all fourteen crests plus the leaflet were already in the tree. The
`support.js` named in the request remains deliberately unshipped — the reason
is recorded in the T-483 source record and has not changed.

### What was blocking a clean handoff

The quiz was 561 lines of TypeScript in which the venue's copy and the scoring
weights were inseparable from the model. Changing a question meant editing
TypeScript inside a pnpm monorepo carrying Three.js, Fastify and Postgres —
roughly a ten-minute install before you could see a single word render.

### What changed

Content and structure were split. Copy and weights moved to
`packages/web/src/features/trades-house/craft-quiz.content.json`, with a JSON
Schema beside it. `craft-quiz-model.ts` now derives `CRAFT_PROFILES` and
`CRAFT_QUESTIONS` from that file at build time; the JSON is assigned to
declared interfaces, so tsc checks its shape on every build. No duplicate copy,
no codegen step, no runtime validator shipped to browsers.

Structure stayed in TypeScript on purpose: `CRAFT_ORDER` (there are fourteen
Incorporated Trades as a matter of history), the ranking and tie-break, and the
icon set.

`projects/trades-house/` is the new front door:

- `AGENTS.md` — the contract. Orientation, the content/structure rule as a
  lookup table, verification commands, and a "decided — do not undo" list
  covering the QR destination, the unshipped `support.js`, the fourteen Crafts
  and the deliberate absence of a wide-screen layout.
- `README.md` — the map, current state, and open work.
- `preview/quiz.html` — a zero-install preview that reads the real content, the
  real crests and the real `ICON_PATHS`, so it cannot drift from what ships. It
  additionally shows live scores and each option's weights, which the shipped
  quiz hides.
- `tools/check.mjs` — dependency-free validation.

### The QR code

Blake flagged the QR as possibly needing adjustment. It was decoded from the
SVG path data from scratch — format bits, mask, zigzag traversal, byte mode —
and is correct: a version-3, EC level M code encoding
`https://www.tradeshallglasgow.co.uk`. The decoder is now part of `check.mjs`,
so the destination is asserted on every run. It stays pointed at the venue site
rather than the quiz; retargeting is a campaign decision, not a defect.

### What the checker found

Walking all 262,144 answer paths shows the quiz is severely unbalanced:
gardeners win 21.1%, coopers 0.1% — a spread near 200:1. Two questions award
`gardeners: 3` outright while the Coopers never rise above a secondary weight.
A visitor is effectively never told they are a Cooper.

This was **not** fixed here. Reweighting is a content decision about how the
fourteen Crafts should be represented, which belongs to Blake and the venue.
Raised as T-540 and recorded as the headline open item in the project README
and AGENTS.md.
