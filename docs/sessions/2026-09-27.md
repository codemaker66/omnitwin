### The dashboard shell (T-635 N1/N2 items)

Built on `claude/cool-tesla-90zlcp`:

- **Notifications on the register.** `NotificationCenter` painted a near-black panel inside the ivory
  More menu and was forced into shape by `!important` overrides. It now reads `--reg-*`:

  - the tone named beside each dot: "Urgent", "Needs attention" or "Update", never the raw value;
  - text actions: "View", "Mark read" and "Refresh". Each accessible name starts with its visible
    words, for example "Mark read: Guest count updated".

  patch went with them. The header ring still measures 2 px ink with no halo.
