### Bounded stored-ZIP SOG v2 facts

The Source Facts second pass still hashes every byte and now invokes SOG
random-access inspection through the same already-open, identity-checked
`FileHandle`; the inspector accepts no path and cannot reopen the source.
The completed main SHA-256 is passed into that observer; the returned SOG
outcome carries the exact source SHA-256 and size, and collector finalization
requires both to equal its independently observed complete stream. A same-size,
different-digest substitution regression now proves that an inspection outcome
cannot be paired with another source. Post-inspection handle/path identity
checks and the unchanged receipt digest binding remain in force. The artifact
still states that this is not an atomic filesystem snapshot.

Fixed fences are 64 ZIP entries, 4 MiB central directory, 1 MiB `meta.json`,
JSON depth 64 and 100,000 values, 32 MiB per WebP member and 128 MiB aggregate
WebP bytes. JSON is fatal-UTF-8, finite-number and duplicate-key checked. ZIP
inspection rejects encryption, ZIP64, multidisk, deflation, unsupported flags,
unsafe/duplicate names, prefixes, unaccounted gaps, overlaps, header/size/CRC
contradictions and missing/extra meta-selected members. The observed XGRIDS
layout uses standard signed 32-bit data descriptors; each is accepted only when
its `0x08074b50` signature, CRC and both sizes agree exactly with the bounded
central entry. Valid zero CRC/size placeholders in descriptor-bearing local
headers are described as fields *consistent with* the central directory, not
as literally equal. Real 12-byte unsigned descriptors return one stable
unsupported outcome in final and non-final positions. Cancellation is checked
again after the final identity `stat()`. Unsigned/ambiguous descriptors remain
unsupported.

Established facts are intentionally narrow:

- SOG version 2 and positive declared Gaussian count;
- declared/default antialias state and generator-field presence, without
  emitting the generator value;
- encoded `means.mins`/`means.maxs`, never labelled physical bounds;
- SH0/higher-order presence, bands and palette count;
- exact member/container totals, stored-method state, CRC/header/descriptor/
  range/member-set checks;
- complete WebP RIFF member structure, VP8L header, dimensions and CRC for canonical
  per-Gaussian and SH planes, without emitting member filenames; and
- shared per-Gaussian pixel capacity and the exact declared-count fit.
