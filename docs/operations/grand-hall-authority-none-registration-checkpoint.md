immutable. A future non-empty checkpoint would require a new packet identity
and fresh revision-1 lineage. A qualified human must first select each visually
identifiable feature using distinct, source-derived ARF and CVF evidence bytes.

generated, or inpainted evidence is inadmissible.

separate immutable successor and must bind exact OBJ face ordinals, ordered

considered.
