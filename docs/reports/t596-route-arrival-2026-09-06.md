# Grand Hall route arrival

The old route fallback showed a generic box, implementation wording and an operational-review chip while JavaScript loaded. The new fallback gives an explicitly requested Grand Hall a full-screen composition using the existing venue image, labelled as event-styling inspiration. Other or unknown rooms use a neutral background without claiming a Grand Hall identity. The shared Activity indicator is the only animation. The page keeps a home/venue link, has one polite work status, uses no synthetic progress, and disappears when Suspense resolves without waiting for the image or a timer.

No new image was generated or edited. The existing `grand-hall-room-1120.webp` and its 480px derivative are already in the public venue image ladder. The 1120px file is 228,806 bytes. The separate `walk-poster-1120.webp` was inspected and rejected for this use because it shows another room. The styling photograph is not presented as the currently saved furniture arrangement, an interactive rendering or reconstruction evidence.
