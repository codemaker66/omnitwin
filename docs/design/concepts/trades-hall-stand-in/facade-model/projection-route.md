# Projection route decision

Verdict: skip reference projection.

The modelling reference is a local crop of the repository's frontal façade photograph. Its pixels contain baked daylight, cast shadows, occlusion, neighbouring buildings, street furniture, and the flagpole, so they are not trustworthy runtime albedo. Repository rights notes also leave publication and external AI-processing rights unresolved for some captured venue imagery. The reference therefore remains local and is never uploaded, bundled as a runtime texture, or presented as cleared photographic content.

The stand-in instead uses shallow procedural geometry, instanced repeated features, and independently relightable PBR-like materials. The frontal photograph controls the visible bay rhythm. Sandstone variation, copper patina, glazing, and ground-contact grime are bounded procedural material responses rather than projected photography.

This route is also the lower-cost browser option: no large projection texture is loaded, exterior context can be disabled for lean/mobile rendering, and the façade remains presentation-only rather than affecting plan dimensions or collision.
