```text
Create one focused service-recovery screen for Daniel's cold-room concern. This is the illustrative branch where Sam has recorded an adjustment but nobody has yet checked Daniel's outcome. Keep the frozen demo clock 14:10 and label the screen “Simulated recovery step”. The separate extra-guest request remains pending at 132; the current event stays 120 under v7.
```
