# Hallkeeper presentation route

Use the signed-in founder account on venviewer.com. Hallkeeper is a primary navigation item for venue staff; hallkeeper accounts land on Today's rooms. Platform administrators retain their platform landing page and can open Hallkeeper directly.

## Start with the real work

1. Open [Today's rooms](https://venviewer.com/hallkeeper/today), or enter [venviewer.com/hallkeeper](https://venviewer.com/hallkeeper). The day board uses actual rooms, booking windows and named phases; its clock labels describe scheduled time, not a completed physical check. At live verification on 7 September it displayed three active bookings across four rooms. The prepared demonstration event was not shown in that active-booking view, so use the direct shortcut below for its working documents.
2. Open the [prepared demonstration event](https://venviewer.com/ops/events/fa64096b-4bbe-4d76-87a8-2b938343d863). The working-document links connect the current setup sheet and the compiled handoff pack.
3. Open the [approved Grand Hall sheet](https://venviewer.com/hallkeeper/3b18bfc3-4a40-4723-8130-13134c80e16e). Show the approval version, saved floor plan, setup categories, quantities, practical instructions and PDF control. Select categories or highlight layout items without marking checks during the presentation.
4. Open the [compiled handoff pack](https://venviewer.com/ops/handoff/b57fda8d-4dfb-4f85-a1ee-0a0b953096f5). Its compiled version is distinct from current shared checklist progress.

At verification, the event was named “DEMO ONLY - Elaine room-planning rehearsal 2026-09-07 - do not book or send”; its approved configuration sheet retains “DEMO ONLY - Codex planner rehearsal 2026-09-06 - do not book or send”. Keep the existing records and approved layout intact. The approved sheet supplies zero guests; furniture counts do not establish attendance. Sheet times labelled indicative are estimates, not confirmed doors or a room-release decision.

## Then show the full workflow design

Open the [Hallkeeper workflow walkthrough](https://venviewer.com/hallkeeper/walkthrough). This is the interactive Hillside House concept using fictional people, dates and events. It demonstrates preparation, setup, checks, hosting, reset and handback with six distinct pastel colours, plus changes, care requests, break cover and handover. Stage labels accompany colour.

The demonstration can be clicked freely. Its state exists only in the isolated walkthrough and resets when leaving or using Restart. It sends no changes to venue APIs. The live page explicitly labels it as fictional; this is a presentation of the intended complete workflow, not a claim that all those automations already persist operational records.

Suggested explanation: “This first sheet uses the actual approved room layout and shared setup work. This next view shows how the whole hallkeeper day will connect, from preparation to handback.”

## Presentation checks

- Confirm sign-in and today's selected venue before beginning.
- Keep the real day board, approved sheet and walkthrough in separate tabs.
- Show the real sheet's category strip and floor plan on desktop; the layout also stacks on a phone.
- Use the walkthrough for interactive changes and handover demonstrations. Real sheet checkboxes save shared progress.
- Use the PDF control on the real sheet when demonstrating the printable working copy.

Deployment identity and live verification are recorded in [live verification](live-verification.md) and the dated session entry, rather than inferred from these URLs.
