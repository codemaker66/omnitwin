# Trades House media

Served at `/trades-house-media/`. `leaflet.html` is the finished two-sided A4
visitor leaflet and opens on its own in any browser; `assets/` holds the
fourteen Craft crests, the venue photography and the QR code, and is also used
by the Craft quiz.

Everything here is static and deployed verbatim, this signpost included. Keep
it to assets and the leaflet — **working documents, content files and tooling
belong in `projects/trades-house/`**, not in a folder that ships to production.

Working on the leaflet or the quiz? Start at
[`projects/trades-house/AGENTS.md`](../../../../projects/trades-house/AGENTS.md).
