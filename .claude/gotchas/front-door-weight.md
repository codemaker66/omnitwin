**Read this when:** adding a static import to `router.tsx`, `main.tsx`, `RoomsHomePage.tsx`, `ProtectedRoute.tsx` or anything the entry loads; regenerating the splat manifest (`lcc2 stage`); changing `site.css`, the mirrored fonts or `index.html`'s font links; or reading a front-door load time.

# The front door's weight is set by static imports

Measured 16 October 2026 on a cold phone-profile load of `/`: 432,136 bytes of fonts and 219,146 bytes of Brotli JavaScript, with the route chunks requested ~1.5 s after the entry's. Fixed 20 October 2026 by the "front-door fonts and chunks" change (numbers in `docs/sessions/2026-10-20.md`). What keeps it fixed:

- **Clerk is for signed-in routes only.** `ProtectedRoute` is imported by `router.tsx`, so it once pulled `@clerk/react` (via `useClerk`, for a sign-out button) into the entry. The button is now `ClerkExitButton.tsx`, lazy-loaded behind an error boundary. Any new `@clerk/*` import in a module the entry or the home route reaches puts the 35 KB chunk back; the build now fails (`src/lib/home-route-preload-plugin.ts`).
- **The splat manifest is for the walk and planner.** `data/generated/trades-hall-splat-bundles.ts` is ~215 KB of tile digests (40 KB Brotli). The home cards read `data/room-card-facts.ts`, generated by `scripts/derive-room-card-facts.mjs`. After any `lcc2 stage` run, regenerate it; `front-door-weight.test.ts` fails when they drift.
- **Fonts: `files/` and `site*.css` are Google's bytes and stay untouched** (`self-hosted-font-files.test.ts`). `index.html` links `site-slim.css`, derived by `scripts/slim-site-fonts.py`: each Latin face is split into `latin-core` (ASCII plus the site's copy characters) and `latin` (Google's file, the remaining range). Only glyphs are dropped; `scripts/verify-slim-fonts.py` proves outlines, advances, kerning, chosen glyphs and hinting are identical. A new non-ASCII character in the site's copy fails `self-hosted-slim-fonts.test.ts`: add it to `CORE_EXTRA`, rerun the script and the verifier.
- **Do not trim axes without Blake.** Limiting `wght` to the `@font-face` descriptors would save ~19 KB more on `/`, but re-basing a variable font's default moves points by a unit or two and advances by up to 0.1% of an em. The hero animates `SOFT` and `WONK`, so those axes cannot go either.
- **Do not preload fonts.** Chrome holds rendering for font preloads in `<head>`; they delayed first paint (measured 24 September). The chunk preload for `/` is a separate, path-gated script written at the `<!-- home-route-preload -->` marker in `index.html`, placed before the stylesheet links so it does not wait for them.
- **Local numbers are not live numbers.** The same phone profile gave LCP ~7.4 s on a local HTTP/2 build and ~5.2 s live. Compare a change only against the same setup.
- **Git Bash rewrites arguments that start with `/`** (`/login` became `c:/Program Files/Git/login`), so a measurement script given a route path silently measured nothing. Set `MSYS_NO_PATHCONV=1`.
